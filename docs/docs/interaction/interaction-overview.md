# Interaction and behavior

Make a card respond when someone taps it or when entity values change.

## :material-horseshoe: Choose a behavior

| Goal | Use |
| --- | --- |
| Open details, toggle an entity, navigate, or run an action | [Actions](actions.md) |
| Show, hide, or disable a tool based on the current card state | [Visibility](visibility.md) |
| Change or animate a tool when an entity reaches a state | [Animations](animations.md) |
| Let someone directly choose a value | [Interactive controls](../tools/controls/controls-overview.md) |

Start with the behavior you need and add dynamic templates only when a fixed value is not enough.
