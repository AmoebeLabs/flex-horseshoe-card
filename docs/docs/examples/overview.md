# Examples

The example pages show complete cards rather than one isolated feature. They are useful when you want to see how Horseshoes, Sparklines, entity information, shapes, controls, colors, and reuse techniques work together in a finished design.

This page points to the available example collections and explains how to use an example as a starting point for your own card.

## :material-horseshoe: Electricity cards

See [Electricity cards](demo-cards/demo-card-electricity-many.md) for complete cards that combine Horseshoes, entity values, colors, history, and reuse.

## :material-horseshoe: Pollen cards

See [Pollen cards](demo-cards/demo-card-kleenex-pollen-many.md) for categorical values, color scales, and alternative layouts.

## :material-horseshoe: Awair cards

See [Awair cards](demo-cards/demo-card-awair-many.md) for air-quality values, interactive choices, and different graph forms.

## :material-horseshoe: Server cards

See [Server cards](demo-cards/demo-card-server-many.md) for system values, multiple entities, and compact dashboard layouts.

## :material-horseshoe: Find the feature used by an example

When an example contains something you want to reuse, open the matching topic under Card tools, Appearance, Interaction, or Reuse. Those pages explain the smaller functional piece without requiring you to work out the complete example first.
