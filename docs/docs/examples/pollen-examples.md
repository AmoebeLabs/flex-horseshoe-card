# Pollen examples

These cards show tree, grass, and weed pollen levels as named states with matching icons, colors, and horseshoe segments.

![Pollen card](../assets/screenshots/fhs-demo-card-55-kleenex-pollen-radar--dark.webp){width="300"}

## :material-horseshoe: What these examples demonstrate

- state-based color stops;
- labels for named states;
- external SVG icons;
- several related horseshoes in one card;
- `same_as`, `ref()`, and `calc()` for shorter YAML;
- color filters that keep the active level prominent.

The examples use entities supplied by the Kleenex Pollen Radar integration and external pollen SVG files.
