# Refactor Source Size by Plan

## Counting method

Counts cover product-owned JavaScript files under `src/`, excluding `src/frontend_mods/` (copied Home Assistant code). Tests, documentation and `dist/` are excluded. Acorn identifies comments: physical lines containing code are counted as code, comment-only lines as comments, and whitespace-only lines as blank.

For Plans 01–12, each change is measured from that plan PR's first-parent commit to its merge commit. Plan 13 is measured from the pre-refactor baseline to its completed feature-branch result. This attributes source changes to the plan PRs instead of unrelated commits between them.

Baseline immediately before Plan 01: `13456ad`, 69 files, 22,197 code lines, 5,492 comment lines, 3,142 blank lines; 30,831 lines total.

## Current size

At Plan 13's completed feature revision `b72a574`, product-owned source is 71 files: 23,782 code lines, 5,696 comment lines and 3,193 blank lines; 32,671 lines total. That is 1,840 lines above the pre-Plan 01 snapshot. The Plan PRs account for 1,362 of those lines; 478 lines came from other source changes between the measured plan PRs.

The full `src/` count also includes 1,655 lines in `frontend_mods`, for 34,326 lines total. Those copied Home Assistant files are outside the product-owned trend above.

The cleanup removed 926 source lines overall, not 1,026 as previously estimated. Plan 13's deletion is included in all net figures above.
