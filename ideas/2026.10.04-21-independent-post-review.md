## Architecture Audit

- **Gate 1:** [main.js](../src/main.js#L174) publishes the current HA context to templates, HomeAssistant, child cards and actions before `updateSourceEntities()` can return. The gate compares declared entity object identity, local-input and first-initialization state, supported locale/display/theme context, and retained owner work ([main.js](../src/main.js#L206)). Its early return precedes entity-config evaluation, groups, tools, animations and parent `requestUpdate()` ([main.js](../src/main.js#L224)). This also resolves Pass B's initially reported stale action-client issue; the final integration disposition and current source agree ([Pass B](../ideas/2026.10.04-21-whole-source-pass-b.md#L183), [Main regression](../tests/plan21-main-update.test.js#L52)).
- **Startup and Gate 2:** An empty `runtimeEntityConfigs` list on first HA delivery does not skip initialization: `!entityConfigsInitialized` makes the first context relevant, after which the current runtime list is scanned ([main.js](../src/main.js#L208), [initial-delivery regression](../tests/plan21-main-update.test.js#L77)). Marked tools evaluate on initial publication or an accepted JS context; equal evaluated output skips translation and config-dependent publication, while changed output proceeds through the existing owner path ([base-tool.js](../src/base-tool.js#L87)). Theme/mode changes enter the same context route, so supported theme-dependent JavaScript is refreshed.
- **Normal rendering and ordering:** Accepted runtime work now reaches `requestUpdate()` without a generic final-presentation comparison ([main.js](../src/main.js#L354)). Animation styles are selected before ordinary and nested state assignment and Sparkline legend refresh ([main.js](../src/main.js#L356)); Text measurement remains an owner operation through `setState()` and `setEffectiveStyles()` ([text-tool.js](../src/text-tool.js#L536)). Async measurement completion requests its own update only after current-owner/revision checks ([text-tool.js](../src/text-tool.js#L824)). Palette, History, icon, path and interaction completions likewise remain owner-scoped; they do not restart the full HA/config pipeline.
- **Implicit sun input and caches:** Enabled day/night Sparkline work explicitly compares the current `sun.sun` state even when it is not a declared card entity; nested Controls forward retained owner requirements ([sparkline-graph-tool.js](../src/sparkline-graph-tool.js#L1717), [control-base.js](../src/control-base.js#L332)). The measured Horseshoe `runtime.mappingKey` was removed; path definitions, measurements, samples and gradient geometry remain independently owned. Sparkline History/data/geometry, async identities, and text-measurement invalidation remain. The baseline diagnostic supports removing mapping identity as a contract, not claiming a universal speedup ([targeted cache audit](../ideas/2026.10.04-21-targeted-cache-audit.md#L9)).
- **JS dependency contract:** Public documentation now states that entities whose changes must immediately reevaluate JavaScript belong in `entities`, including direct `states`/`hass.states` reads ([javascript-templates.md](../docs/docs/dynamic/javascript-templates.md#L80)). Browser contracts cover undeclared reads remaining stale until a legitimate update and declared reads updating immediately ([card-change-detection.browser.spec.js](../tests/card-change-detection.browser.spec.js#L382)).
