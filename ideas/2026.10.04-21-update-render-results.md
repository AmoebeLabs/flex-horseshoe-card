## Implementation

- Main always publishes HA context to connection/template/action owners and child cards. Irrelevant deliveries then stop before entity/config/group/tool/animation/render work.
- Declared raw HA entity identity, local mutation, initialization, locale/display and theme changes determine normal input relevance. Implicit day/night `sun.sun` input remains owned by History/GraphTool.
- Marked JavaScript is evaluated on the existing relevant context route. Equal evaluated config retains the existing active config and avoids translation/reconstruction.
- Removed the generic presentation comparison from Main, CardTools and the complete tool hierarchy. Relevant runtime publication requests a Lit update even when rounded text stays equal.
- Removed duplicate formatted state/attribute storage and comparisons in Main. Formatting remains with its display owner; attributes and small raw numeric changes still reach consumers.
- Animation styles are selected before ordinary/nested state text is measured. `CardAnimations.update()` no longer serializes before/after style maps to return a render decision.
- Temporary parent-selected styles now use `setEffectiveStyles()` and `runtime.effectiveStyles`, including Icon's custom renderer. Complete replacement and explicit clearing preserve the previous style contract.
- Removed the measured Horseshoe mapping key; direct value mapping is inexpensive in the representative diagnostic. Historical data, path geometry, gradient geometry, SVG measurement and async identities retain their own targeted caches.

The first focused browser pass caught an initialization error: no current runtime entity config exists on the first HA delivery. Main now scans the currently published runtime list, while the existing initialization flag admits the first config evaluation. A direct Main regression covers an empty initial list.

The whole-source Pass B also caught stale HA client publication for actions after an irrelevant update. The client now advances before Gate 1 without opening the rejected FHS processing route.
