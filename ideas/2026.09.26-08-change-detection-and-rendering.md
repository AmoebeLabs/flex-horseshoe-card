## 4. Required change rules

Input may matter, effective result changed, and presentation needs updating are separate decisions. Rounded text equality applies only to text. Raw measurements still reach applicable statistics, color-stop, icon and animation owners.

| Effective change | Required work |
| --- | --- |
| Relevant inputs and presentation unchanged | Publish current context; skip unnecessary calculations and rendering. |
| Same formatted text, changed color/unit/icon/style | Update affected presentation; retain equal text measurements. |
| Graph measurement or time window changed | Update affected data/statistics; geometry/presentation follow changed results. |
| Width/margins changed, effective bins unchanged | Geometry using retained processed data. |
| Automatic bins changed | Reaggregate retained rows; fetch only missing source coverage. |
| Source/period/offset/aggregate changed | Reconsider data inputs/coverage; do not assume a fetch. |
| Pure color/opacity/palette changed | Paint only; no history, aggregation, statistics or normal geometry. |
| Measurement-affecting styles changed | Layout/geometry without reaggregation when data inputs remain equal. |
| Pointer or animation frame | Existing targeted presentation route; no normal graph-data rebuild. |

Conservatively evaluate marked JavaScript when HA context, theme, locale or published derived values may matter, then compare effective output. An unrelated HA entity can still be relevant to JavaScript.
